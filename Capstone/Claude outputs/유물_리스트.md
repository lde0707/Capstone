# 쓰레기 집게 소년 — 유물 리스트 (58종)

## 구조

```
지하에서 발굴          지상 복원소에 투입          도시에 나타남
화석 / 깨진 물건   →   시안 빛에 감싸여 복원   →   🚶 배회형  or  🗿 전시형
```

- **🚶 배회형** — 복원되면 살아나서 마을을 어슬렁거린다 (주민 NPC와 같은 방식)
- **🗿 전시형** — 마을 빈 자리에 좌대와 함께 설치된다 (장식물과 같은 방식)
- **깊이** — 1층(지표 근처) ~ 4층(최심부). 깊을수록 희귀하고 비싸다

## 미정 — 정해야 할 것

1. **복원 소요 시간** — 즉시 / 실시간 N초 / 다음 날 아침
2. **복원 비용** — 무료 / 돈 / 다른 쓰레기 소모
3. **중복 발굴** — 같은 유물을 또 캐면? (돈으로 자동 환전 추천)
4. **배회형 상한** — 26종이 전부 돌아다니면 화면이 터진다. 동시 배회 수 제한 필요
5. **도감 UI** — 발견/미발견을 실루엣으로 보여주는 화면
