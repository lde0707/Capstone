# 쓰레기 집게 소년 (프로토타입)

지하 매립지에서 쓰레기를 파내 지상 처리장에 넘기고, **하루 할당량을 못 채우면 해고**당하는 게임.
Unity 6.3 (URP 2D) + New Input System. `SampleScene` 을 열고 **Play**.

## 하루 사이클

```
아침: 정착 지원금과 오늘 할당량 발표 (250 → 400 → 600 → 900 → 1,350 → 2,000 → 3,000원)
낮 (6분): 해가 동쪽에서 서쪽으로 이동 — 일몰 전까지 쓰레기 수집·지상 반입
정산: 미달이면 게임 오버 / 마감 때 지하에 있으면 가방 몰수
밤: 시간 정지 — 상점(능력치·장비·펫·시설), 일당·먹이값 지급
7일을 버티면 승리
```

## 조작법

| 입력 | 동작 |
| --- | --- |
| W / A / S / D | 중력 없이 네 방향 이동하며 마지막 입력 방향의 인접 한 칸 조준 |
| Space | 표시된 인접 한 칸을 길게 눌러 굴착 |
| E | 왼쪽 지상 분리수거장에 가방 투입 / 오른쪽 처리장에서 강화 상점 |
| H / J | 발견한 지하 분리수거장 위에서 수거 / 운반 일꾼 고용 |
| Q | 쓰레기 탐지기 (구입 후) — 주변 쓰레기가 벽 너머로 3초 표시 |
| B | 귀환 벨 (구입 후) — 하루 1회 즉시 지상 귀환 |
| F | 에너지 드링크 — 기력 +30 |
| Enter | 밤 화면에서 다음 날 시작 |
| Tab / Shift+R | 도움말 토글 / 새 게임 |

## 핵심 시스템

- **부피 가방** — 쓰레기마다 부피(1~4)가 있다. 병뚜껑을 잔뜩 담을지 브라운관 TV 하나를 담을지 매번 선택. 힘·기력 강화, 거북이 펫, 압축기가 용량을 늘린다
- **재질 7종** — 일반 / 고철 / 유리 / 플라스틱 / 전자제품 / **유해 폐기물(방호복 없이 주우면 체력 -12)** / 유물(잭팟)
- **매립층 4개** — 최근 매립층(생활 쓰레기) → 90년대 층(가전) → 산업 폐기물층(유해물, 방호복 필요) → 봉인된 최심층(유물). 층별 보물 색: 은백 → 에메랄드 → 사파이어 → 자수정
- **자연스러운 매립지** — 한 칸 1.5배 크기, 가로 183칸. OPP 32px 연속 암반과 16방향 통로 타일이 자연 연결·직선/곡선 통로·막힌 끝을 자동 갱신한다
- **무중력 탐사** — 낙하 없이 파낸 통로 안에서 WASD로 자유롭게 오르내린다
- **기력** — 지상에서만 0.1초당 5 회복. 0이면 굴착 불가
- **시야** — 타일에 끊기지 않는 원형 시야. 헤드랜턴(+1/+2), 반딧불이(+1)로 확장
- **지하 분리수거장·일꾼** — 숨은 폐기물 집하 구역(2x2~3x3), 수거/운반 자동화. **일당제**: 매일 밤 자동 지급, 못 주면 떠난다
- **지상 분리수거장** — 쓰레기를 들고 가서 E로 투입한다. 분류 설비 가동 시 판매가 x1.3, 확장 시 x1.5
- **펫 (1마리 동행, 먹이값 40원/일)** — 두더지(비싼 쓰레기 방향 화살표) / 반딧불이(시야 +1) / 거북이(가방 +6)

## 자주 만질 밸런스 값 (`Core/GameConfig.cs`)

| 값 | 의미 |
| --- | --- |
| `DayLengthSeconds` | 하루 길이 (기본 6분) |
| `QuotaForDay` / `DailyQuotas` | 일차별 수동 조정 할당량 곡선 |
| `DaysToWin` | 승리 일수 |
| `BaseBagVolume` | 가방 기본 용량 |
| `HazardPickupDamage` | 유해물 맨손 피해 |
| `MinerWage` / `HaulerWage` / `PetFeedCost` | 유지비 |
| `RecycleBonus1` / `RecycleBonus2` | 분리수거장 판매 배율 |
| 각 장비 `*Cost` | 상점 가격 |

쓰레기 이름·가격·부피는 `Core/LootTable.cs`.
