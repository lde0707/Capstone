# 쓰레기 집게 소년 (프로토타입)

지하 매립지에서 쓰레기를 파내 지상 처리장에 넘기고, **하루 할당량을 못 채우면 해고**당하는 게임.
Unity 6.3 (URP 2D) + New Input System. `SampleScene` 을 열고 **Play**.

## 하루 사이클

```
아침: 정착 지원금과 오늘 할당량 발표 (250 → 400 → 600 → 900 → 1,350 → 2,000 → 3,000원)
낮 (2분): 해가 동쪽에서 서쪽으로 이동 — 마지막 20초 경고 전에 쓰레기 수집·지상 반입
정산: 미달이면 게임 오버 / 마감 때 지하에 있으면 가방 몰수
밤: 시간 정지 — 상점(능력치·장비·펫·시설), 일당·먹이값 지급
7일을 버티면 승리
```

## 조작법

| 입력 | 동작 |
| --- | --- |
| W / A / S / D | 중력 없이 네 방향 이동하며 마지막 입력 방향의 인접 한 칸 조준 |
| Space | 표시된 인접 한 칸을 길게 눌러 굴착 |
| E | 지상 분리수거장 투입 / 처리장 강화 / 도시광산 안전 보관·회수 |
| H / J | 도시광산에서 20초 자동 재활용 / 보관함 대량 운반 일꾼 고용 |
| Q | 쓰레기 탐지기 (구입 후) — 주변 쓰레기가 벽 너머로 3초 표시 |
| B | 귀환 벨 (구입 후) — 하루 1회 즉시 지상 귀환 |
| F | 에너지 드링크 — 기력 +30 |
| Enter | 밤 화면에서 다음 날 시작 |
| Tab / Shift+R | 도움말 토글 / 새 게임 |

## 핵심 시스템

- **부피 가방** — 쓰레기마다 부피(1~4)가 있다. 병뚜껑을 잔뜩 담을지 브라운관 TV 하나를 담을지 매번 선택. 힘·기력 강화, 거북이 펫, 압축기가 용량을 늘린다
- **재질 7종** — 일반 / 고철 / 유리 / 플라스틱 / 전자제품 / **유해 폐기물(방호복 없이 주우면 체력 -12)** / 유물(잭팟)
- **매립층 4개** — 최근 매립층(생활 쓰레기) → 90년대 층(가전) → 산업 폐기물층(유해물, 방호복 필요) → 봉인된 최심층(유물). 층별 보물 색: 은백 → 에메랄드 → 사파이어 → 자수정
- **자연스러운 매립지** — 한 칸 1.5배 크기, 가로 183칸. OPP 32px 연속 암반과 16방향 통로 타일이 자연 연결·직선/곡선 통로·막힌 끝을 자동 갱신한다
- **지상 잔디 지반** — 초록 잔디가 아래로 3칸 이어지고 파괴할 수 없다. 스폰 오른쪽 2칸의 고정 통로로 지하에 진입한다
- **무중력 탐사** — 낙하 없이 파낸 통로 안에서 WASD로 자유롭게 오르내린다
- **기력** — 지상에서만 0.1초당 5 회복. 0이면 굴착 불가
- **시야** — 타일에 끊기지 않는 원형 시야. 헤드랜턴(+1/+2), 반딧불이(+1)로 확장
- **도시광산·일꾼** — 발견 즉시 고철 샘플 2개. E로 가방을 안전 보관·회수한다. H 일꾼은 단독으로 20초마다 1개를 자동 재활용하고, J 일꾼은 보관함을 5개씩 대량 운반한다. 보관품은 마감 몰수 대상이 아니다. **일당제**: 매일 밤 자동 지급, 못 주면 떠난다
- **지상 분리수거장** — 쓰레기를 들고 가서 E로 투입한다. 분류 설비 가동 시 판매가 x1.3, 확장 시 x1.5
- **펫 (1마리 동행, 먹이값 40원/일)** — 두더지(비싼 쓰레기 방향 화살표) / 반딧불이(시야 +1) / 거북이(가방 +6)

## 자주 만질 밸런스 값 (`Core/GameConfig.cs`)

| 값 | 의미 |
| --- | --- |
| `DayLengthSeconds` | 하루 길이 (기본 2분, 마감 경고 20초) |
| `QuotaForDay` / `DailyQuotas` | 일차별 수동 조정 할당량 곡선 |
| `DaysToWin` | 승리 일수 |
| `BaseBagVolume` | 가방 기본 용량 |
| `HazardPickupDamage` | 유해물 맨손 피해 |
| `MinerWage` / `HaulerWage` / `PetFeedCost` | 유지비 |
| `RecycleBonus1` / `RecycleBonus2` | 분리수거장 판매 배율 |
| 각 장비 `*Cost` | 상점 가격 |

쓰레기 이름·가격·부피는 `Core/LootTable.cs`.

## 지상 문명 — 하루의 보상

땅 파는 노동이 **눈에 보이는 것으로 남게** 하는 시스템. (`World/Village.cs`)

```
1일차 시작 : 지상 한가운데 다 쓰러져가는 판잣집 한 채 + 잡초 몇 개 + 주민 1명
할당량 달성 순간 : 빛기둥이 솟고 집이 한 단계 커진다 (정산까지 기다리지 않는다)
                   + 이웃집 1채, 소품 1개, 주민 2명
다음 날 아침     : 이웃집 1채, 소품 2개, 주민 2명이 더 들어온다
                   집이 늘수록 흙길 → 자갈길 → 벽돌길로 포장된다
7일차          : 시계탑이 선 시청 + 십수 채의 집 + 주민 18명 = 도시
```

### 집 6단계

| 단계 | 이름 | 조건 |
| --- | --- | --- |
| 0 | 다 쓰러져가는 판잣집 | 시작 |
| 1 | 초가 오두막 | 1회차 할당량 달성 |
| 2 | 벽돌집 | 2회차 |
| 3 | 2층 저택 | 3회차 |
| 4 | 3층 석조 대저택 | 4회차 |
| 5 | 시계탑이 선 시청 | 5회차 |

마을 단계 이름(`Village.StageName`)은 `허허벌판 → 작은 정착지 → 마을 → 번화한 읍내 → 도시`
로 바뀌고 HUD 우측 상단과 밤 정산 화면에 항상 표시된다.

### 주민 NPC

`World/Villager.cs`. 상호작용은 없다. 마을 범위 안을 느리게 걸어다니다가 가끔 멈춰 서고,
방향이 바뀌면 스프라이트가 좌우로 뒤집힌다. 최대 18명.

### 조절 포인트

| 값 | 위치 | 의미 |
| --- | --- | --- |
| `GameConfig.SkyRows` | GameConfig.cs | 지상 하늘 높이 (도시가 커질 공간). 기본 10칸 |
| `Village.NeighborOffsets` | Village.cs | 이웃집이 들어설 자리 (중심에서의 칸 오프셋) |
| `Village.PropOffsets` / `PropCycle` | Village.cs | 소품 자리와 등장 순서 |
| `Villager.WalkSpeed` | Villager.cs | 주민 이동 속도 |
| `VillageUpgradeFx` | Village.cs | 업그레이드 빛기둥·반짝이 연출 |
