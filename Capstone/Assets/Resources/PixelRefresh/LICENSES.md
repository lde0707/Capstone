# Pixel refresh asset licenses

All assets in this folder are used under CC0 1.0 (public domain dedication). Attribution is not required, but the original creators and download pages are recorded here.

- `Ground/tileset*.png` — **Dirt Tileset**, TinyWorlds. 16px dirt tiles in six palette variants. Source: https://opengameart.org/content/dirt-tileset
- `Player/*.png` — **Simple Autorunner Sprites (16x16)**, TheLuigiplayer. MoleMan character animation frames. Source: https://opengameart.org/content/simple-autorunner-sprites-16x16
- `Factory/recycler_factory.png` — **Core Reactor Machines**, Reactorcore. Pixel machine sprite `6.png`. Source: https://opengameart.org/content/core-reactor-machines
- `Products/recycled_products.png` — **27 Items / Icons**, Kutejnikov. 32px item icon sheet. Source: https://opengameart.org/content/27-items-icons

The source pages listed all four packs as CC0 when downloaded on 2026-08-31.
