# Environment pixel assets

The following free assets are included in this folder.

- `natural_cave_autotile_32.png` — modified (nearest-neighbour resize from 64px to 32px) from **Cave Platformer Tileset 47** by second, CC0: https://opengameart.org/content/cave-platformer-tileset-47
- `db32_cave_tileset.png` — **DB32 Cave tileset** by Buch, CC0: https://opengameart.org/content/db32-cave-tileset
- `trash_can.png` — **Trash can** by Christopher Smith / ItzNinjaFool, CC0 option selected: https://opengameart.org/content/trash-can-0
- `recycle_items.png` — **Recycle items set** by Clint Bellanger, CC-BY 3.0 / OGA-BY 3.0: https://opengameart.org/content/recycle-items-set
- `opp_cave_background.png`, `opp_cave_rock_tiles.png` — **OPP 2017 - Cave and mine cart** by Open Pixel Project contributors, CC0 / public domain: https://openpixelproject.itch.io/opp2017cave
- `opp_cave_passages_32.png` — derived from the two OPP files above. The 32px tiles combine four-direction masks for fully connected spaces, straight/corner passages, T-junctions, and one-way dead ends.

`recycle_items.png` is used as cropped facility signage. Original recycle item art by Clint Bellanger.
