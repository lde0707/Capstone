# 설계안: 「쓰레기 집게 소년」 (가제)

> 지하에 파묻힌 쓰레기를 파내서 지상 처리장에 넘기고, 하루 할당량을 못 채우면 잘리는 게임.
> 현재 프로토타입(땅파기 게임)의 코드 뼈대를 그대로 재활용할 수 있게 설계했다.

---

## 0. 참고 게임에서 뽑은 요소 요약

| 게임 | 훔쳐올 요소 | 우리 게임에서의 형태 |
| --- | --- | --- |
| 리썰 컴퍼니 | **점점 오르는 할당량**, 사이클제(3일 단위 정산), 시간 압박(밤이 되면 위험), 아이템 슬롯 제한 | 일일 할당량이 날마다 상승, 하루가 끝나기 전 귀환 필수 |
| 돔 키퍼 | **낮/밤 2페이즈 루프**, 갓 지하에서 주운 가젯이 플레이 방식을 바꿈, 리프트·탐지 프로브 | 채굴 페이즈 ↔ 정산/정비 페이즈, 지하에서 줍는 "고장난 가젯" |
| 굴착소년 쿵 | 광물 가격 테이블의 명확한 티어, **장비 단계 업그레이드**(곡괭이·드릴·가방) | 집게 → 자석집게 → 진공흡입기 장비 트리 |
| 코어 키퍼 | **펫**, 스킬이 쓰면 늘어나는 성장, 기지 확장, 컨베이어 자동화 | 쓰레기 탐지 펫, 분리수거장 + 컨베이어 |
| 뒷산에서 보석캐기 | 광산별 테마·봉인 해제 진행, **균등 업그레이드** 같은 편의 기능 | 깊이별 "매립층" 테마, 잠긴 구역 해금 |
| 드릴 코어(추가 조사) | 낮에 캐고 밤에 방어하는 사이클, 할당량 미달 = 실패 | 일일 정산 구조의 근거 |

## 1. 게임 한 문장

**"낮에는 지하 매립지에서 쓰레기를 파내 할당량을 채우고, 저녁에는 번 돈으로 장비·시설·동료를 갖춰서 내일 더 깊은 곳의 더 비싼 쓰레기를 노리는 게임."**

---

## 2. 핵심 루프 (하루 = 1사이클)

```
[아침] 할당량 발표 (예: 오늘 800점)
   ↓
[낮] 지하로 내려가 쓰레기 수집 → 지상 처리장에 반입 (여러 번 왕복)
   ↓
[저녁 5분 전] 경고 — 아직 지하에 있으면 위험
   ↓
[정산] 할당량 달성? ─ 아니오 → 게임 오버 (해고)
   ↓ 예
[밤] 상점/업그레이드/시설 설치/일꾼 고용 (시간 무제한, 안전)
   ↓
[다음날 아침] 할당량 상승 + 새 매립층 조금 더 깊게 개방
```

리썰 컴퍼니의 "3일 정산"과 달리 **매일 정산**을 추천한다. 세션이 짧아 긴장 주기가 빨라지고, 프로토타입 단계에서 밸런스 확인도 쉽다. 대신 할당량 상승 곡선을 완만하게 잡는다 (예: 1일차 500 → 2일차 800 → 3일차 1,200 → …, 약 1.5배씩).

### 지금 코드에서 바뀌는 것
- 제한시간 30분 1판 → **하루 5~7분 × N일** 구조 (`TimeLimitSeconds`를 하루 길이로 재사용)
- 누적 판매액 목표 → **오늘의 할당량** (달성 시 리셋, 미달 시 게임 오버 — 이미 있는 `TargetValue` 판정 재사용)
- 보물 → 쓰레기 아이템 테이블 교체 (`LootTable` 이름·색만 교체)

## 3. 쓰레기 시스템 (기존 보물 대체)

### 3-1. 쓰레기에 "부피"를 추가한다 ★핵심 제안

지금 가방은 개수 제한뿐이라 모든 보물이 동일하다. 쓰레기마다 **부피(1~6칸)**를 주면:

- 병뚜껑(부피1, 5점) 100개 vs 냉장고(부피6, 400점) 1개 — **무엇을 담을지가 매번 선택**이 된다
- 가방 업그레이드가 "칸 수 증가"로 직관적이 된다
- 대형 쓰레기(가전제품 등)는 혼자 못 들고 **끌고 가야** 해서(이동속도 저하) 일꾼/장비의 가치가 올라간다

### 3-2. 재질 분류 — 분리수거 시스템의 기반

| 재질 | 예시 | 특징 |
| --- | --- | --- |
| 일반 | 비닐, 음식물 찌꺼기 | 흔하고 쌈. 그냥 내면 됨 |
| 캔/고철 | 깡통, 파이프, 자전거 | 자석 장비에 끌려옴 |
| 유리 | 병, 어항 | **떨어뜨리면 깨져서 가치 하락** — 낙하 중력과 연동되는 재미 |
| 플라스틱 | 페트병, 장난감 | 가볍고 부피 큼 |
| 전자제품 | 라디오, 냉장고, 배터리 | 비싸지만 크고 무거움. **분해하면 부품**이 나옴 |
| 유해 폐기물 | 배터리 액, 의료 폐기물 | 맨손으로 들면 체력이 닳음 — 방호 장비 필요 |
| 유물급 | 금시계, 옛날 동전, 골동품 | 매립지에 가끔 섞여 있는 잭팟 (리썰 컴퍼니의 고가 스크랩 포지션) |

**분리해서 내면 보너스**: 처리장에 그냥 쏟으면 100%, 재질별로 분리 배출하면 130~150% 가격. 분리수거장 시설(아래)이 이걸 자동화해준다.

### 3-3. 매립층 = 깊이별 테마 (기존 4개 지층 재활용)

| 층 | 테마 | 나오는 것 |
| --- | --- | --- |
| 1층 | 최근 매립층 | 생활 쓰레기, 캔, 병 — 싸지만 흔함 |
| 2층 | 90년대 층 | 가전제품, 브라운관 TV, 오락기 부품 |
| 3층 | 산업 폐기물층 | 고철 덩어리, 드럼통, 유해 폐기물 (방호복 필요 → 자연스러운 진행 게이트) |
| 4층 | 봉인된 최심층 | 유물급 쓰레기, 정체불명의 물건 — "왜 이런 게 묻혀 있지?" 스토리 훅 |

힘 업그레이드로 단단한 층을 뚫는 기존 구조가 그대로 진행 게이트로 작동한다.

## 4. 장비·아이템 (지루함을 깨는 핵심)

### 4-1. 수집 장비 트리 (굴착소년 쿵 스타일 단계 업그레이드)

```
집게       → 긴 집게     → 자석 집게        → 진공 흡입기
(1칸 앞)     (2칸, 사거리↑)  (금속류 자동 끌림)   (주변 소형 쓰레기 자동 흡입)
```

### 4-2. 소모품 / 도구 (돔 키퍼 가젯 + 리썰 컴퍼니 장비 참고)

| 아이템 | 효과 | 왜 재미있나 |
| --- | --- | --- |
| 손전등 → 헤드랜턴 | 시야 반경 +1 / +2 | 이미 있는 포그 시스템과 바로 연동 |
| 쓰레기 탐지기 | 주변 10칸 내 쓰레기가 벽 너머로 2초간 표시 (돔 키퍼 프로브) | 포그+숨겨진 쓰레기와 연동, "어디를 팔까"가 정보 게임이 됨 |
| 휴대용 사다리 / 로프 | 수직굴에 설치, 낙하 없이 오르내림 | 중력 시스템과 연동 |
| 에너지 드링크 | 지하에서 기력 30 즉시 회복 (1일 구매 제한) | "한 번 더 파고 올라갈까" 선택지 |
| 방호복 | 유해 폐기물을 잡아도 무피해 | 3층 진행 게이트 열쇠 |
| 휴대용 압축기 | 가방 안 쓰레기 부피 30% 감소 | 부피 시스템과 연동 |
| 귀환 벨 | 즉시 지상으로 (1일 1회, 비쌈) | 마감 직전 극적 탈출 (리썰 컴퍼니 텔레포터) |
| 대형 쓰레기용 수레 | 냉장고급을 끌 때 감속 없음 | 대형 쓰레기 시스템과 연동 |

### 4-3. 펫 (요청 요소, 코어 키퍼 참고)

밤 상점에서 입양. **한 마리만 동행** — 뭘 데려갈지가 하루 전략이 된다.

| 펫 | 능력 |
| --- | --- |
| 두더지 | 근처의 가장 비싼 쓰레기 방향을 가리킨다 (요청하신 "위치 알려주는 펫") |
| 갈매기 | 소형 쓰레기(부피1)를 물어다 지상에 놓는다 — 느리지만 공짜 운반 |
| 거북이 | 등껍질이 이동 가방 (+4칸) |
| 반딧불이 | 주변 시야 +1, 어두운 곳에서 쓰레기가 반짝임 |

펫은 먹이(하루 유지비)가 들어서, 초반엔 사치품 → 중반엔 필수품이 되는 곡선을 만든다.

## 5. 시설·자동화 (요청 요소: 분리수거장 + 일꾼)

지상 처리장 옆 부지에 **시설을 짓는다**. 기존 2x2 강화 건물 코드를 복사해서 확장.

| 시설 | 효과 | 업그레이드 |
| --- | --- | --- |
| 분리수거장 | 쏟아 넣으면 자동 분류 → 판매 보너스 130% | 처리 속도, 보너스율 150%까지 |
| 고물 분해대 | 전자제품을 분해해 부품 획득 — 부품은 장비 제작 재료 | 희귀 부품 확률 |
| 컨베이어 승강기 | 지정한 수직굴에 설치 — 쓰레기를 넣으면 자동으로 지상까지 (돔 키퍼 리프트) | 속도, 동시 적재량 |
| 간이 숙소 | 일꾼 고용 한도 +2 | 한도 +2씩 |
| 재활용 공방 | 잡동사니 쓰레기 N개 → 소모품 1개 제작 | 레시피 해금 |

### 일꾼 (기존 채굴/운반 일꾼 확장)

| 일꾼 | 역할 | 기존 코드 |
| --- | --- | --- |
| 수거 일꾼 | 지정 구역을 돌며 소형 쓰레기를 줍는다 | 채굴 일꾼 AI 변형 |
| 운반 일꾼 | 쌓인 쓰레기를 지상 분리수거장까지 | **이미 있음** (BFS 운반) |
| 분류 일꾼 | 분리수거장에 상주, 처리 속도 2배 | 신규 (정적 배치라 구현 쉬움) |

일꾼에게 **일당**을 준다 (매일 정산에서 차감). 자동화가 공짜가 아니라 "일당 이상을 벌어오는가"를 계산하게 만든다 — 이게 방치형과 다른 긴장 포인트.

## 6. 긴장 요소 (지루함의 직접 해결책)

수집·업그레이드만 있으면 결국 또 루틴이 된다. 리썰 컴퍼니가 무서운 이유는 **잃을 수 있어서**다. 최소 2개는 넣는 걸 추천:

1. **밤이 오면 지하가 위험해진다** — 저녁 이후 지하에 남아 있으면 시야 반경 1로 축소 + 체력이 계속 닳음. "한 탕 더" 욕심의 대가. (구현: 기존 깊이 데미지 코드에 시간 조건 추가 — 아주 쉬움)
2. **가스 주머니** — 특정 타일을 파면 유독 가스 분출, 몇 초간 주변 체력 감소. 파기 전 탐지기로 확인 가능 → 탐지기 가치 상승. (구현: 타일 1종 추가)
3. **붕괴** — 넓게 판 공간의 천장이 가끔 무너져 흙이 다시 차고, 깔리면 큰 피해. 마구 파는 플레이에 제동. (구현 난이도 중)
4. **들개/쥐 떼** — 쓰레기를 물고 도망가는 잡몹. 전투가 아니라 **쫓아내기/뺏기기**라 톤이 가볍다. (구현 난이도 중상)
5. **죽으면 가방을 그 자리에 떨군다** — 리썰 컴퍼니식. 다음날 회수하러 가는 동기 부여. (구현: 쉬움)

## 7. 왜 이 조합이 재미있나 (설계 의도)

- **매일이 마감** — "오늘 못 채우면 끝"이라는 리썰 컴퍼니식 압박이 수집 행위에 의미를 부여한다. 지금 프로토타입이 지루한 건 30분 목표가 너무 멀어서다.
- **낮에 번 돈을 밤에 쓰는 리듬** — 돔 키퍼의 2페이즈 구조. 긴장(낮)과 계획(밤)이 번갈아 와서 단조롭지 않다.
- **모든 시스템이 서로 물린다** — 부피→가방→수레→일꾼, 포그→랜턴→탐지기→펫, 유해물→방호복→3층. 돔 키퍼 개발자가 말한 "서로 먹여주는 시스템" 원칙.
- **자동화는 보조, 주인공은 플레이어** — 일당 시스템 덕에 방치형으로 흐르지 않고, 플레이어는 항상 "더 깊은 곳"이라는 최전선에 있다.

## 8. 구현 우선순위 (기존 코드 기준)

| 단계 | 내용 | 난이도 |
| --- | --- | --- |
| 1 | 일일 할당량 사이클 (하루 타이머 + 정산 + 상승 곡선) | 하 — 기존 타이머/목표 코드 개조 |
| 2 | 보물 → 쓰레기 테이블 교체 + 부피 시스템 | 하 |
| 3 | 밤 상점 페이즈 (기존 강화 상점 확장) | 하 |
| 4 | 손전등·탐지기·사다리 (기존 포그/중력과 연동) | 중 |
| 5 | 분리수거장 + 분류 보너스 | 중 |
| 6 | 펫 (두더지부터) | 중 |
| 7 | 긴장 요소 1~2개 (밤 위험 + 가방 떨구기 추천) | 중 |
| 8 | 컨베이어 승강기, 대형 쓰레기, 들개 | 상 |

1~3만 해도 "매일 마감이 있는 쓰레기 수집 게임"이 성립한다. 4~7에서 재미가 붙고, 8은 살이다.
