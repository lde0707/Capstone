# 분리수거 미니게임 기획서

## 1. 개요

플레이어가 수집한 쓰레기를 **현재 게임에 이미 존재하는 지상 쓰레기 판매 건물(지상 분리수거장)**에 맡긴 뒤, 숫자 키로 종류를 빠르게 판별하여 처리하는 리듬게임형 미니게임이다. 별도의 신규 건물은 만들지 않는다.

- `E`: 기존 쓰레기 판매 건물에 소지한 쓰레기를 투입하고 대기열에 등록
- `F`: 같은 건물과 상호작용하여 미니게임 시작
- `1`~`5`: 현재 쓰레기의 분리수거 종류 선택
- `Esc`: 미니게임 종료 및 일반 플레이 화면으로 복귀

정답을 입력하면 쓰레기가 정상적으로 분리수거되고 다음 쓰레기가 중앙 칸으로 이동한다. 오답을 입력하면 분리수거에 실패하며 오염도가 증가한다.

---

## 2. 플레이 흐름

1. 플레이어가 쓰레기를 소지한 상태로 기존 지상 쓰레기 판매 건물에 접근한다.
2. `E`를 누르면 소지한 쓰레기를 해당 건물에 내려놓는다.
3. 내려놓은 쓰레기는 분리수거 대기열에 순서대로 저장된다.
   - 작업대에는 최대 30개까지 저장한다.
   - 남은 자리보다 소지한 쓰레기가 많으면 빈자리만큼만 저장하고 나머지는 가방에 유지한다.
   - 30개가 차면 작업대 건물 위에 `가득 참!` 말풍선을 표시한다.
4. 같은 건물 근처에서 `F`를 누르면 분리수거 UI가 열린다.
5. 대기열의 첫 번째 쓰레기가 화면 중앙 상단의 현재 쓰레기 칸에 크게 표시된다.
6. 그다음 쓰레기는 현재 쓰레기 오른쪽의 대기 칸에 조금 작게 표시된다.
7. 플레이어가 현재 쓰레기가 표시된 뒤 2초 안에 맞는 숫자 키를 누른다.
8. 정답, 오답 또는 시간 초과 결과를 짧게 표시한다.
9. 처리된 쓰레기는 대기열에서 제거되고, 다음 쓰레기가 중앙 칸으로 이동한다.
10. 대기열이 빌 때까지 7~9번 과정을 반복한다.
11. 플레이어는 진행 중 언제든 `Esc`를 눌러 UI를 닫을 수 있다.

### 기존 판매 방식에서 변경되는 점

현재 구현은 지상 쓰레기 판매 건물 앞에서 `E`를 누르면 가방의 쓰레기를 즉시 재활용·판매한다. 미니게임 적용 후에는 아래와 같이 변경한다.

| 구분 | 현재 동작 | 변경 후 동작 |
|---|---|---|
| 건물 | 기존 지상 쓰레기 판매 건물 | 동일한 건물 그대로 사용 |
| `E` 입력 | 가방의 쓰레기를 즉시 판매 | 쓰레기를 건물의 분리수거 대기열에 보관 |
| `F` 입력 | 기존 판매 기능과 무관 | 보관된 쓰레기가 있으면 미니게임 UI 열기 |
| 판매 시점 | `E` 입력 직후 | 미니게임에서 해당 쓰레기를 올바르게 분류했을 때 |
| 오답 처리 | 없음 | 판매 실패 및 오염도 증가 |

즉, 기존 건물의 위치, 외형, 접근 판정은 재사용하고 `E`의 즉시 판매 로직을 대기열 등록 방식으로 교체한다.

## 3. 입력 키와 분류 기준

| 키 | 분리수거 종류 | 예시 |
|---:|---|---|
| `1` | 캔 | 철제 통조림 캔, 스틸 캔 |
| `2` | 페트 | 생수병, 음료 페트병 |
| `3` | 종이 | 신문지, 종이 상자, 종이 포장재 |
| `4` | 플라스틱 | 플라스틱 용기, 장난감, 비닐류 |
| `5` | 알루미늄 | 알루미늄 포일, 알루미늄 용기 |

> `캔`과 `알루미늄`의 의미가 겹치지 않도록, 이 문서에서는 캔을 철제 캔류로 정의하고 알루미늄은 포일·용기류로 정의한다. 추후 게임의 쓰레기 목록에 맞춰 명칭이나 분류 기준을 변경할 수 있다.

## 4. UI 구성

### 4-1. 기본 배치

```text
                         [ 다음 쓰레기 ]
          [       현재 분리수거할 쓰레기       ]
          [            큰 이미지              ]   [작은 이미지]

              판정 메시지: 성공! / 실패!

        [1 캔] [2 페트] [3 종이] [4 플라스틱] [5 알루미늄]

                  남은 쓰레기: 8개
                 오염도: ███░░░░░░░

                      ESC 나가기
```

### 4-2. 현재 쓰레기 영역

- 화면 중앙 상단에 큰 정사각형 프레임으로 배치한다.
- 현재 판별해야 하는 쓰레기 이미지를 프레임 안에 크게 표시한다.
- 이미지 비율이 깨지지 않도록 원본 비율을 유지한다.
- 현재 입력이 어느 쓰레기를 대상으로 하는지 명확하게 보여준다.

### 4-3. 다음 쓰레기 영역

- 현재 쓰레기 칸의 오른쪽에 배치한다.
- 현재 쓰레기보다 작은 정사각형 프레임과 이미지로 표시한다.
- 대기열에 다음 쓰레기가 없으면 빈 칸으로 두거나 `마지막 쓰레기`라고 표시한다.

### 4-4. 분류 안내 영역

- 화면 하단 또는 중앙 하단에 `1`~`5` 키와 분류명을 항상 표시한다.
- 눌러야 하는 정답 키를 직접 강조하지 않는다.
- 입력 직후 선택한 버튼을 잠깐 점등하여 플레이어에게 입력 피드백을 준다.

### 4-5. 판정 및 상태 표시

- 정답: 초록색 `분리수거 성공!` 문구와 성공 효과
- 오답: 빨간색 `분리수거 실패!` 문구와 실패 효과
- 시간 초과: 빨간색 `시간 초과!` 문구와 실패 효과
- 현재 물건마다 2초에서 줄어드는 남은 시간 게이지를 표시한다.
- 남은 쓰레기 개수를 표시한다.
- 현재 오염도를 게이지 또는 수치로 표시한다.

## 5. 성공 및 실패 판정

### 성공

현재 쓰레기에 설정된 분류 값과 플레이어가 누른 숫자 키의 분류가 같으면 성공이다.

- 성공 효과음과 시각 효과를 재생한다.
- 해당 쓰레기를 정상 처리한다.
- 필요할 경우 점수, 돈, 재활용 자원 등의 보상을 지급한다.
- 대기열의 다음 쓰레기를 현재 칸으로 이동한다.

### 실패

현재 쓰레기의 분류와 다른 숫자 키를 누르거나, 현재 쓰레기가 중앙 칸에 들어온 뒤 2초 안에 선택하지 못하면 실패다.

- 실패 효과음과 시각 효과를 재생한다.
- 오염도를 1칸 증가시킨다.
- 해당 쓰레기는 실패 처리 후 대기열에서 제거한다.
- 대기열의 다음 쓰레기를 현재 칸으로 이동한다.

### 연속 입력 방지

- 판정 연출과 다음 쓰레기 전환 중에는 숫자 입력을 잠시 막는다.
- 한 번의 키 입력으로 한 개의 쓰레기만 처리되도록 한다.
- 권장 판정 및 전환 시간은 약 `0.3~0.6초`이며 실제 플레이 테스트 후 조절한다.

> 제한 시간은 물건마다 2초다. 판정·전환 연출 중에는 타이머를 멈추고, 다음 쓰레기가 중앙 칸에 들어오면 다시 2초부터 시작한다.

---

## 6. 쓰레기 전환 연출

입력 결과가 나온 뒤 다음과 같이 화면을 전환한다.

1. 처리한 현재 쓰레기 이미지가 사라지거나 분리수거함 방향으로 이동한다.
2. 오른쪽에서 대기하던 다음 쓰레기가 중앙의 큰 칸으로 이동하며 확대된다.
3. 그다음 순서의 쓰레기가 오른쪽 대기 칸에 새로 표시된다.
4. 전환이 끝나면 숫자 입력을 다시 허용한다.

대기열이 모두 비면 `분리수거 완료!` 문구를 표시한 뒤 UI를 닫거나, 플레이어가 `Esc` 또는 확인 키를 눌러 나가게 한다.

---

## 7. 오염도 시스템 연동

분리수거 실패 시 전역 또는 해당 지역의 오염도가 증가한다.

- 오답 1회당 오염도 `+1칸`, 정상 분리수거 1회당 `-1칸`으로 처리한다.
- 오염도는 최소 `0`, 최대 `10칸` 범위로 제한한다.
- 미분류 대기열을 남기고 다음 날로 넘어가면 오염도가 `+1칸` 증가한다.
- 오염도 1칸마다 굴착 시간이 100% 증가하고 지하의 보라색 오버레이가 짙어진다.
- 미니게임 UI에 현재 오염도를 즉시 반영한다.
- 오염도 10칸에서는 기본 굴착 시간의 11배가 적용된다.

초기 구현에서는 아래 기능까지만 포함한다.

- 오답 발생 감지
- 오염도 수치 증가
- UI 게이지 갱신

## 8. 상태별 동작

| 상태 | 허용 입력 | 동작 |
|---|---|---|
| 일반 플레이 | `E`, `F` | 쓰레기 투입 또는 미니게임 진입 |
| UI 열림 / 입력 대기 | `1`~`5`, `Esc` | 분류 선택 또는 나가기 |
| 판정 및 전환 중 | `Esc` | 숫자 입력은 잠금, 나가기는 허용 |
| 대기열 없음 | `Esc` 또는 확인 키 | 완료 메시지 표시 후 종료 |

UI가 열려 있는 동안에는 플레이어 이동, 공격, 도구 사용 등 일반 플레이 입력을 막는다. UI를 닫으면 이전 입력 상태와 게임 조작을 복구한다.

## 9. 예외 처리

- 소지한 쓰레기가 없을 때 기존 판매 건물에서 `E`: `버릴 쓰레기가 없습니다.` 안내 표시
- 작업대가 30개로 가득 찼을 때 `E`: 추가 투입을 막고 `가득 참!` 말풍선과 로그 표시
- 대기열이 비어 있을 때 `F`: `분리수거할 쓰레기가 없습니다.` 안내 표시
- 기존 판매 건물 근처가 아닌 곳에서 `E` 또는 `F`: 이 시스템은 동작하지 않음
- UI가 열린 상태에서 `E` 또는 `F`: 중복 실행 방지
- 숫자 키를 동시에 여러 개 누른 경우: 가장 먼저 감지된 유효 입력 하나만 처리
- 제한 시간 2초가 끝난 프레임의 숫자 입력: 시간 초과를 우선 처리하고 다음 쓰레기 입력으로 넘기지 않음
- 마지막 쓰레기 처리 후: 빈 이미지를 잠깐 노출하지 않고 완료 상태로 전환
- `Esc`로 중간 종료: 아직 처리하지 않은 쓰레기는 대기열에 그대로 보존

## 10. 데이터 구조 제안

### 쓰레기 데이터

각 쓰레기는 최소한 다음 정보를 가진다.

| 필드 | 설명 |
|---|---|
| `Id` | 쓰레기 고유 ID |
| `DisplayName` | 화면에 표시할 이름 |
| `Sprite` | UI에 표시할 이미지 |
| `RecycleType` | 캔, 페트, 종이, 플라스틱, 알루미늄 중 하나 |
| `Reward` | 성공 시 지급할 보상 값 |
| `PollutionPenalty` | 실패 시 증가할 오염도 값 |

### 기존 쓰레기 판매 건물에 추가할 데이터

| 필드 | 설명 |
|---|---|
| `TrashQueue` | 투입된 쓰레기의 순서가 저장된 대기열 |
| `CurrentTrash` | 현재 판별 중인 쓰레기 |
| `NextTrash` | UI 오른쪽에 미리 보여줄 쓰레기 |
| `IsMinigameOpen` | 미니게임 UI 활성화 여부 |
| `IsTransitioning` | 판정 및 전환 연출 진행 여부 |

## 11. 구현 단위 제안

- 기존 `GameManager`의 지상 분리수거장 상호작용: 현재 판매 건물의 접근 판정을 재사용하고 `E` 투입, `F` 미니게임 진입 처리
- `RecyclingQueue`: 쓰레기 대기열 추가, 조회, 제거
- `RecyclingMinigameUI`: 현재/다음 이미지, 키 안내, 판정 문구 표시
- `RecyclingMinigameController`: 입력, 정답 판정, 다음 쓰레기 전환 관리
- `PollutionManager`: 오염도 증가, 범위 제한, UI 갱신
- `TrashData`: 쓰레기 이미지와 올바른 분류 정보를 보관하는 데이터

## 12. 1차 구현 범위

### 포함

- 기존 지상 쓰레기 판매 건물의 접근 및 상호작용 재사용
- 기존 건물에서 `E`로 쓰레기 대기열 등록
- 같은 건물에서 `F`로 분리수거 UI 열기
- 현재 쓰레기와 다음 쓰레기 이미지 표시
- `1`~`5` 키를 이용한 분류
- 물건마다 2초 선택 제한과 남은 시간 게이지
- 성공/실패 판정과 간단한 연출
- 실패 시 오염도 증가
- 다음 쓰레기로 자동 전환
- `Esc`로 미니게임 종료
- 중간 종료 시 남은 쓰레기 보존

### 추후 확장

- 연속 정답 콤보와 점수 배율
- 진행할수록 판정 시간이 짧아지는 난이도 상승
- 특수 쓰레기 또는 복합 재질 쓰레기
- 오염도에 따른 마을/맵 변화와 패널티
- 분리수거장 업그레이드와 자동 분류 기능
- 키보드 외 게임패드 입력 지원

## 13. 완료 조건

아래 조건을 모두 만족하면 1차 기능이 완성된 것으로 본다.

- 쓰레기를 여러 개 넣었을 때 투입 순서대로 등장한다.
- 현재 쓰레기와 다음 쓰레기의 이미지가 서로 다른 크기로 정상 표시된다.
- `1`~`5` 입력이 각 분류와 정확히 연결된다.
- 정답과 오답이 올바르게 판정된다.
- 선택하지 않고 2초가 지나면 실패하고 오염도가 1칸 증가한다.
- 오답 시 오염도가 즉시 증가한다.
- 한 번의 입력으로 쓰레기 하나만 처리된다.
- 처리 후 다음 쓰레기가 중앙 칸으로 자연스럽게 이동한다.
- `Esc` 입력 시 언제든 UI를 닫고 일반 플레이로 돌아간다.
- 중간에 나갔다 다시 들어와도 처리하지 않은 쓰레기가 유지된다.
- 대기열을 모두 처리하면 완료 상태가 표시된다.
